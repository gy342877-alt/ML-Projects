# 🏠 California House Price Prediction

A machine learning regression project that predicts California house prices using **Python, Pandas, and Scikit-learn**.

## 📌 Project Overview

This project demonstrates an end-to-end machine learning workflow for predicting house prices.

The main focus is building a clean and reproducible **Scikit-learn Pipeline** for data preprocessing and model training.

## 🔄 Machine Learning Workflow

```text
Dataset
   ↓
Data Exploration
   ↓
Train / Test Split
   ↓
Data Preprocessing
   ↓
Scikit-learn Pipeline
   ↓
Model Training
   ↓
Model Evaluation
   ↓
House Price Prediction
```

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 🧹 Data Preprocessing

The project includes:

* Handling missing values
* Numerical feature transformation
* Feature scaling
* Combining preprocessing and model training using a Pipeline

## 🤖 Machine Learning Model

A regression model is trained to predict house prices.

Model performance is evaluated using **Root Mean Squared Error (RMSE)** on the test dataset.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/gy342877-alt/California-house-price-prediction.git
```

### 2. Open the project

```bash
cd California-house-price-prediction
```

### 3. Open the notebook

Open `mlproject.ipynb` using **Jupyter Notebook** or **VS Code**.

### 4. Run the notebook

Run the cells from top to bottom to reproduce the data preprocessing, model training, evaluation, and predictions.
